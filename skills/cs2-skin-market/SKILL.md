# CS2 Skin Market Analysis

分析CS2饰品市场的技能。数据源为SteamDT + CSQAQ + Buff。

## 核心数据源

### SteamDT（指数/成交额/品类排行）
- 首页 `https://www.steamdt.com` → Nuxt数据中提取
- 指数约850-900区间，含"连跌X天/连涨X天"标签
- 每天成交量、成交额（CNY）
- 品类排行榜（按品类分涨跌）
- **提取脚本**: See [scripts/fetch_steamdt.py](scripts/fetch_steamdt.py)

### CSQAQ（品类单品级数据）
- API: `https://api.csqaq.com`（需要key）
- 品类下逐件皮肤数据（价格、成交量、走势）
- 热榜、涨跌幅异动
- **提取脚本**: See [scripts/fetch_csqaq.py](scripts/fetch_csqaq.py)

### Buff（成交价/溢价率）
- Buff.163.com 真实成交价
- 与Steam底价的溢价率 = (Buff价 - Steam价) / Steam价
- 高溢价=投机热，低溢价=真实玩家需求

## 市场分析框架

### 维度1：大盘温度（宏观判断）

**关键指标：**
- **SteamDT指数**: 850 = 适中，800以下=恐慌区，900以上=狂热区
- **成交量**: 日均88-100万单正常；>120万=放量异动（利好/利空需判断方向）；<80万=缩量阴跌
- **成交额**: 日均¥13-15亿；>¥18亿=放量；<¥10亿=流动性枯竭
- **连涨/连跌天数**: 连跌4天+是超卖信号（短线反弹概率大）；连涨4天+注意回调
- **贪婪指数CSQAQ**: 0-100，<30=恐慌（可能见底），>80=贪婪（短期顶部）

**走势形态识别：**
- L字底：急跌后横盘缩量 → 企稳信号
- V型底：急跌后急涨 → 大资金抄底（少见）
- 阴跌：每天跌0.2-0.5%，缩量 → 磨底过程
- 放量下跌：恐慌盘出清，抄底党入场 → 多空激烈博弈

### 维度2：品类结构（看子弹往哪飞）

**四大品类及特性：**

| 品类 | 稳定性 | 投机性 | 受政策影响 | 说明 |
|------|--------|--------|-----------|------|
| 刀/手套 | ⭐⭐⭐⭐⭐ | ⭐ | ⭐ | 最硬通缩资产，几乎不新增供应，暴跌后最先反弹 |
| 基础红皮(AWP/M4/AK) | ⭐⭐⭐⭐ | ⭐⭐ | ⭐ | 玩家刚需，波段跟随大盘 |
| 收藏品枪皮 | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ | 受Major纪念品新系统影响大 |
| 胶囊/印花/纪念品 | ⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 最高风险，V社一个补丁就能清零价值 |

**分析方法：**
1. 看品类涨跌排行 — 各品类绿还是红？
2. 看溢价率变化 — 溢价率快速下降=炒作资金撤离
3. 看成交量分布 — 交易集中在什么品类？

### 维度3：政策面（V社更新解读）

**标准分析框架：**

| 更新类型 | 市场影响 | 时间窗口 |
|---------|---------|---------|
| Major公告（新Pass/新胶囊） | 利好（资金流入） | 提前1-2周price in |
| 纪念品自造 | 重击老纪念品、利好新Major消耗 | 持续2-4周 |
| 胶囊改直购 | 杀胶囊估值、贴纸变消费品 | 长期结构改变 |
| 交易冷却/撤回 | 杀流动性、重创短线庄家 | 1-2周消化 |
| Trade Up规则变更 | 影响特定品类供需结构 | 短期冲击+长期稳定 |
| 无钥匙开箱/X光扫描 | 降低开箱成本、影响箱子/钥匙供需 | 1-2周 |

**分析原则：**
- V社不是在"搞搞阵"，是在执行**去金融化+消费化**的长期战略
- 凡是被V社"标准化"的东西（纪念品/胶囊），稀缺价值归零
- 凡是不可复制的东西（基础枪皮/刀手套皮肤），长期价值不受影响
- 恐慌往往过度，但不要跟V社对赌

### 维度4：市场情绪（判断买卖时机）

**恐慌识别信号：**
- 社交媒体一片哀嚎（"退坑了"、"V社杀死了市场"）
- 日跌1%+连续3天
- 成交量维持在90万+但指数持续下跌（多空博弈中抛压占优）
- 高价物品（刀/手套/龙狙）领跌 → 恐慌蔓延到硬通货
- 低价耗材（紫/粉皮）仍然活跃 → 玩家需求还在

**抄底信号（等待至少2项同时出现）：**
1. 大盘缩量企稳（<85万成交量）
2. 连跌天数达到4-5天以上
3. 恐慌信号1-2消失（社交媒体喊底比喊逃多）
4. 硬通货稳住（刀/手套不再新低）
5. V社没有再出新补丁

**清仓信号（跑，不问）：**
- 大盘跌破800且不停新低
- V社继续出针对遗留存量资产的补丁
- 成交量萎缩到<70万且无买盘

## 快速分析流程

```
1. 查大盘指数 + 成交额/量 → 判断宏观温度
2. 看连涨/跌天数 + 贪婪指数 → 判断超买超卖
3. 查品类涨跌排行 → 看钱在哪个品类
4. 查近期V社更新 → 判断政策方向
5. 看高价硬通货走势 → 判断恐慌是否扩散
6. 综合判断：恐慌/狂热/正常？
7. 给出建议：抄底/加仓/持仓/减仓/清仓
```

## 已知洞察（直接使用，不需重新论证）

- V社的长期方向是"去金融化"，纪念品/胶囊的高溢价终将被消灭
- CS2基础市场不会死，因为底层玩家消耗是刚需
- 恐慌期（连跌4天+）之后通常会有一波反弹，但不一定是反转
- Major期间的资金脉冲可以缓冲下跌，但不可持续
- Trade Up机制会创造底部需求（吃低价消耗品）
- 每次V社大更新都是"恐慌→观望→理性评估→分化"的节奏
