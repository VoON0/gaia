# SteamDT指数关键点位参考

> 数据使用Scripts/fetch_steamdt.py实时拉取。此处仅记录历史关键点位和参考区间。

## 支撑位 / 压力位（当前2026.5 约850-870区间）

### 支撑位（向下）
- **860-870**: 当前博弈区间
- **840-850**: 下一个心理支撑（5月前期震荡中轴）
- **820-830**: 强支撑（历史调整常至此区间）
- **800**: 铁底，跌破视为牛转熊

### 压力位（向上）
- **880-900**: 近期顶部
- **920-940**: 高位（2026年5月初）

## 成交量参考区间

| 日成交量(万单) | 含义 |
|--------------|------|
| < 80 | 流动性萎缩，磨底信号 |
| 80-88 | 正常偏低，健康调整 |
| 88-100 | 正常活跃区间 |
| 100-120 | 偏高，有事件驱动 |
| > 120 | 异常放量，确认方向 |

## 日涨跌参考

| 变化 | 市场含义 |
|------|---------|
| > +2% | 强烈买入（注意持续性） |
| +1~2% | 强势 |
| 0~+1% | 温和 |
| 0~-1% | 温和下跌 |
| -1~-2% | 中幅下跌 |
| < -2% | 大幅下跌（可能触发恐慌） |
| 连跌3天+ | 超卖积累 |
| 连跌5天+ | 严重超卖，反弹窗口临近 |
